OVERVIEW

关于 Clash Dash

Clash Dash 是用 SwiftUI 开发的 iOS 管理工具，可连接 OpenClash、Nikki 等已有服务，查看流量、切换策略和编辑配置。它解决的是远程控制与查看状态的问题，使用前需要一台已经运行代理内核的设备。

  • 多服务管理
  • 实时流量与延迟测试
  • 配置与订阅编辑
  • iCloud 同步

维护状态与版本说明

状态待确认

公开仓库仍可访问且未归档；最近核验的发布包为 v1.4.3，未见明确停更公告。

它是控制器，不会自动为 iPhone 建立代理隧道。官方 GitHub 发布 IPA，安装仍需要满足 Apple 的签名与分发条件；下载 IPA 不等于可直接点开安装。

收录版本：v1.4.3 · 发布日期 2025-12-23。版本信息以所列来源为准。
