OVERVIEW

关于 ShellCrash

ShellCrash 原名 ShellClash，是在 Shell 环境中部署和管理 Mihomo、sing-box 等内核的工具。它通过终端菜单组织运行模式、订阅、定时任务和面板设置，覆盖多种路由器与标准 Linux 设备，适合能够使用 SSH 的用户。

  • Shell 菜单管理
  • 支持多种内核
  • 配置与定时任务
  • 路由器与 Linux 适配

维护状态与版本说明

持续维护

官方开发分支持续更新；稳定版发布页为 1.9.4。

ShellCrash 是管理脚本，不是新的 Clash 内核。不同固件的权限、启动服务和防火墙能力不同，先按项目说明确认设备兼容性。页面下载为官方脚本压缩包。
