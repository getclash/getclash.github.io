OVERVIEW

关于 Yacd

Yacd 的全名是 Yet Another Clash Dashboard，是围绕 Clash External Controller 构建的经典 Web 面板。它以简单的流量、策略组、连接与日志界面被众多旧客户端集成，也是 Yacd-meta 等后续项目的基础。

  • 经典仪表盘
  • 代理组选择
  • 连接与日志查看
  • 可自行部署

维护状态与版本说明

状态待确认

原仓库可访问且未归档；稳定发布仍为 2022 年的 v0.3.8，不能仅凭发布间隔断言停更。

经典版本对后来新增的 Mihomo 字段与管理能力可能不完整。继续使用旧面板前，先确认自己的内核版本和所需功能；使用新功能时可比较 Yacd-meta、Zashboard 或 MetaCubeXD。

收录版本：v0.3.8 · 发布日期 2022-11-11。版本信息以所列来源为准。
