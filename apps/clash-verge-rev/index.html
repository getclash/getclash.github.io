OVERVIEW

关于 Clash Verge Rev

原版 Clash Verge 的社区延续，使用 Tauri 2 构建桌面界面。集成 Mihomo 内核，适合需要订阅管理、规则分流与 TUN 模式的 Windows、macOS 和 Linux 用户。

  • Tauri 2 桌面界面
  • 系统代理与 TUN 模式
  • Merge / Script 配置增强
  • WebDAV 备份与同步

维护状态与版本说明

持续维护

截至 2026-10-27，官方仓库未归档，并有近期代码或版本发布。

Rev 与已归档的原版 Clash Verge 是不同维护项目。普通电脑优先选择 x64；Apple Silicon 与 Windows on ARM 选择 ARM64。

收录版本：2.5.8 · 发布日期 2026-10-09。版本信息以所列来源为准。
