OVERVIEW

关于 Mihomo / Clash.Meta

Mihomo 是原 Clash.Meta 内核项目，提供规则路由、DNS、代理集合、TUN 和控制 API 等基础能力。Clash Verge Rev、Clash Meta for Android 等图形客户端会在内核之上提供操作界面；直接下载这里的文件，更适合自行配置服务或管理现有部署。

  • 规则与代理集合
  • TUN 与透明代理
  • DoH / DoT 与 Fake-IP
  • HTTP 控制 API

维护状态与版本说明

持续维护

官方发布页提供 v1.19.33，发布于 2026-10-21。

内核文件不是完整图形客户端。Clash.Meta 是项目的旧称，不需要再额外寻找一个“Clash Meta 内核”。运行权限、配置字段和最低系统要求应以对应版本文档为准。
