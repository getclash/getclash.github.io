关于 Clash Dashboard（原版）

Clash Dashboard 曾是 Dreamacro 名下的 Clash Web 控制面板。旧截图和教程里出现的“Dashboard”未必指今天仍在维护的某一个项目；这条历史记录帮助区分原版面板、Yacd，以及当前面向 Mihomo 的新面板。

  • 早期 Web 控制面板
  • 策略组操作
  • 内核 API 连接
