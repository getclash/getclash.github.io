DOWNLOAD WITH CONTEXT

下载快一点，来源清楚一点。

软件详情页按平台与架构列出安装选项。GitHub 发布资产统一使用加速前缀，项目来源保持可追溯。

GitHub 加速如何工作？

下载按钮把项目 GitHub Release 安装包原地址交给第三方加速服务转发。默认线路为 https://gh-proxy.com/，本站不存储或修改二进制安装包，也不对第三方线路作速度承诺。

只保存在当前浏览器；接受 HTTPS 前缀，网站其他访问者不受影响。

加速服务使用方式：GH-Proxy 使用文档。

找到正确的安装文件

  • Windows：核对 x64 或 ARM64，再选安装程序或便携格式。
  • macOS：Apple Silicon 通常对应 arm64 / aarch64，Intel 对应 x64 / x86_64；Universal 为通用包。
  • Android：按设备架构选择 APK，常见现代手机为 arm64-v8a；无法确认时先查设备信息。
  • Linux / OpenWrt：同时核对发行版、包管理格式、CPU 架构及内核要求。

历史版本如何收录？

归档项目仍保留可核验的官方安装资产时，详情页会注明版本和来源。原始仓库删除或未找到可信文件时，保留项目资料与迁移教程，下载区标注“暂无已核验安装包”。商店分发项目使用项目公布的官方分发入口。

下载后做一次校验

若项目提供 SHA256、签名或校验清单，可在安装前对照。校验值应来自项目维护者公布的渠道。哈希一致表示文件与该校验值对应，不能单独证明软件安全。

查看安装包校验教程

下载中断怎么办？

  1. 先确认安装包所属平台、架构与版本。
  2. 检查项目来源页是否仍保留该资产。
  3. 在本页修改为你信任的 GitHub 加速前缀，再返回软件页重试。
  4. 若项目已经撤回资产，通过 GitHub 反馈，便于核对并更新条目。
